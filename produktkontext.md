# TeamFlow im Kreislaufunternehmen

Fiktiver Unterrichtsfall für Innovieren mit KI (AI x Human, DISRUPT). Alle Personen, Daten und Aussagen sind frei erfunden. Eine Softwareanwendung ist für die erste Quellenübung nicht erforderlich.

Das Unternehmen betreibt Reparaturworkshops. Mitarbeitende und Interessierte möchten freie Plätze und den Status ihrer Anmeldung verstehen. Organisatoren verwalten Kapazitäten; manche Workshops benötigen eine vorherige Genehmigung.

Die aktuelle Aufgabe lautet: Verhindern Sie, dass eine offene Genehmigung mit einer bestätigten Buchung verwechselt wird. Vergleichen Sie dazu die Quellen Q01 bis Q04. Eine neue Idee wird erst nach einer ausdrücklichen Entscheidung verbindlich.

Für Ihre Analyse verwenden Sie folgende Begriffe:

- pending_approval: Anfrage wartet auf Genehmigung.
- confirmed: Buchung ist bestätigt.
- waitlisted: Person steht auf der Warteliste.
- rejected: Anfrage wurde abgelehnt.
- cancelled: Buchung wurde storniert.

Beurteilen Sie zusätzlich, welche Informationen Sie für einen realen Produktentscheid noch benötigen. Behaupten Sie keine tatsächlichen Kundenanteile, Einsparungen oder Zahlungsbereitschaft aus diesen wenigen Kursaussagen.
